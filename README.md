# Human Body Metrics Calculator

## Overview
Human Body Metrics Calculator is a Java Swing-based desktop application developed as a learning project during my 3rd semester of B.Tech.
The application helps users analyze body metrics such as BMI, body fat percentage, visceral fat, muscle mass, metabolic age, and target fitness goals.

---

## Features
- Java Swing GUI
- BMI Calculation
- Body Fat Analysis
- Visceral Fat Analysis
- Muscle Mass Analysis
- Metabolic Age Comparison
- Target Goal Calculation
- Input Validation
- Custom Exception Handling
- Educational Use Agreement
- Clear/Reset Functionality
---

## Technologies Used
- Java
- Swing
- AWT
- OOP Concepts
- Exception Handling

## How to Run

Compile:

```bash
javac pcalc.java
```

Run:

```bash
java calc
```
